    安装 runner¶

    更新apt包索引： sudo apt-get update 安装必备的软件包以允许apt通过 HTTPS 使用存储库（repository）： sudo apt-get install ca-certificates curl gnupg lsb-release

    添加Docker官方版本库的GPG密钥： sudo mkdir -p /etc/apt/keyrings curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg 使用以下命令设置存储库： echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
