2. k8s常见的负载类型有哪些
    1. **Pod**

    最小的调度单元，本质上是对容器的抽象封装。

    通常不直接单独使用，而是通过更高级的控制器来管理。

    2. **Deployment**

    最常用的控制器，用于管理无状态应用。

    特点：支持副本数、滚动更新、回滚。

    使用场景：Web 服务、API 服务。

    3. **ReplicaSet**

    保证指定数量的 Pod 副本始终运行。

    通常不直接使用，而是由 Deployment 管理。

    4. **StatefulSet**

    管理 有状态应用（需要稳定标识、持久存储、顺序部署/扩缩容）。

    特点：Pod 有固定名称（如 pod-0、pod-1）、可结合 PersistentVolume 实现持久化。

    使用场景：数据库（MySQL、PostgreSQL）、分布式系统（Kafka、Zookeeper）。

    5. **DaemonSet**

    确保集群 每个节点上都有一个 Pod（或指定节点）。

    常用于运行守护进程。

    使用场景：日志收集（Fluentd）、监控（Node Exporter）、网络插件（Calico）。

    6. **Job**

    用于执行 一次性任务，任务完成后 Pod 退出。

    使用场景：批处理任务、数据迁移、脚本任务。

    7. **CronJob**

    基于 时间调度 的 Job，类似 Linux 的 crontab。

    使用场景：定时任务（数据库备份、日志清理）。
